# 🎮 Tic-Tac-Toe Game

A simple implementation of the classic **Tic-Tac-Toe (Noughts and Crosses)** game using **HTML, CSS, and JavaScript**.

## 📌 About
Tic-Tac-Toe is a two-player game where one player chooses **X** and the other chooses **O**.  
Players take turns marking spaces in a **3×3 grid**. The first player to align three of their marks (horizontally, vertically, or diagonally) wins the game. If all cells are filled without a winner, the game ends in a **draw**.

This project demonstrates:
- ✅ Game logic in JavaScript  
- ✅ DOM manipulation  
- ✅ Event handling  
- ✅ Responsive UI with CSS  

---

## 🚀 Features
- 🎯 Two-player gameplay (Player X vs Player O)  
- 🔄 Restart/Reset functionality  
- 🏆 Winning highlight when a player wins  
- 🤝 Draw detection  
- 💻 Simple and responsive UI  

---

## 🛠️ Tech Stack
- **HTML** – Structure of the game board  
- **CSS** – Styling and layout  
- **JavaScript** – Game logic & interactivity
